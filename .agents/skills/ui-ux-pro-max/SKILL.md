# UI UX Pro Max Skill

## Core Principles
- Establish curated color tokens using modern HSL and CSS custom variables (`--bg-glass`, `--accent-primary`, `--border-glass`, `--status-warning`, `--status-success`).
- Use frosted glass cards (`backdrop-filter: blur(16px); background: rgba(255,255,255,0.03); border: 1px solid rgba(255,255,255,0.08)`).
- Ensure consistent spacing scale (4px grid system: 8px, 16px, 24px, 32px, 48px).
- Provide vibrant visual cues (glowing status badges, micro-animations, subtle button hover elevations).
