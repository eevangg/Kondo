# Frontend Security Coder

Guidelines for client-side web application security:
- Escape user-generated text inputs to prevent Cross-Site Scripting (XSS).
- Avoid rendering untrusted HTML using `dangerouslySetInnerHTML`.
- Protect sensitive data stored in local session storage.
