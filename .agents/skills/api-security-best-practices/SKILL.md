# API Security Best Practices

Guidelines for secure API communication and data access control in HomeSync:
- Validate authentication tokens on all API requests.
- Restrict cross-origin resource sharing (CORS) to trusted domains.
- Enforce strict JSON content-type headers.
- Never expose API keys or service role secrets in client-side bundles.
