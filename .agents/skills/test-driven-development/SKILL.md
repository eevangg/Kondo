# Test Driven Development Skill

## TDD Workflow
- Define input/output expectations for core domain functions (e.g. `calculateBalances()`, `syncLowStockToShopping()`).
- Verify calculation logic with edge cases (e.g. 0 expenses, odd division cents rounding, reverse settlements).
- Refactor helper functions for clarity while keeping tests passing cleanly.
