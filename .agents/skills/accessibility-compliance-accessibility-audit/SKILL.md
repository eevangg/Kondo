# Accessibility Compliance Skill

## Audit Standards
- Maintain contrast ratio >= 4.5:1 for standard text on dark glass backgrounds.
- Provide proper `aria-label`, `role`, and focus states (`:focus-visible`) for interactive elements.
- Ensure full keyboard navigation support across tabs, action buttons, and modal dialogs.
