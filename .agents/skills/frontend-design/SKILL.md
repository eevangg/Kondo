# Frontend Design Skill

## Guidelines
- Prioritize visual excellence and rich aesthetics over plain MVP designs.
- Use Google Fonts (Inter / Outfit) with defined font-weight scales.
- Implement responsive grid and flexbox layouts with consistent gap metrics.
- Add smooth transition animations (`transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1)`).
- Structure components logically into dedicated single-responsibility React modules.
