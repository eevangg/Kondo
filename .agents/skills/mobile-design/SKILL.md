# Mobile Design Skill

## Mobile-First Principles
- Design touch targets with minimum 44x44px dimensions.
- Responsive breakpoints at `640px` (mobile), `768px` (tablet), `1024px` (desktop).
- Bottom navigation tabs or collapsible header controls on small viewports.
- Fluid typography and touch-friendly modal sheets for quick action logging.
