# Systematic Debugging Skill

## Protocol
- Inspect complete console outputs, network request payloads, and Supabase client error logs before diagnosing issues.
- Trace state mutations across parent-child React components.
- Verify exact financial balance math (Who Owes Whom net calculations) with concrete test cases.
- Never swallow exceptions silently or return fake fallback data without explicit root cause analysis.
