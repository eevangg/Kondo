# Lint and Validate Skill

## Validation Checklist
- Ensure zero syntax errors in JSX and JavaScript files.
- Validate component import paths and file exports.
- Run project build validation (`npm run build`) to confirm production compile stability.
- Ensure strict prop checking and state initialization checks to prevent runtime errors.
